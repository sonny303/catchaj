# Catchaj product story

## Goal
Build a polished, responsive single-page product story for Catchaj that feels like warm paper, precise ink, and a thoughtfully constrained tool—not generic AI software.

## What I’ll build
- A restrained header and editorial opening with the “Truth Document → staged application → human pause” story.
- The three guiding principles and concise problem narrative.
- An accessible six-helper interface with keyboard navigation and a focused detail panel.
- A working “Judge’s Seat” with score, location, and account-friction controls that updates the verdict instantly.
- The inverted “most important feature is a pause” centerpiece, product-choice details, and closing call to action.
- Mobile layouts with large touch targets and contained content at 320–480px widths.

## Visual direction
- Archival paper base, deep forest ink, sage/olive accents, lime reserved for meaningful status.
- Modern sans typography with a warm italic serif for human emphasis.
- Fine rules, sharp editorial rhythm, tactile stamps, restrained motion, no gradients or decorative effects.

## Technical details
- Implement in the existing TanStack React page using Tailwind v4 semantic tokens.
- Keep content data separate from presentation and use existing Radix-based controls.
- Add page-specific search and social metadata.
- Validate desktop and mobile rendering plus keyboard behavior for helper tabs.
